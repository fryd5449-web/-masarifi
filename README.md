# فلافي

صفحة مالية محلية لمتابعة رأس المال والمبيعات والأرباح لمشروع المخبوزات.

كل البيانات تحفظ في LocalStorage داخل المتصفح باستخدام المفتاح `fluffy-business-v1`، ولا توجد خدمة خلفية أو طلبات شبكة.

الرئيسية تعرض آخر 5 عمليات. صفحة `operations.html` تفصل المبيعات والمشتريات وتستخدم نفس البيانات والمحرر.
الكشف يُحسب عند الطلب من فترة شاملة ليومي البداية والنهاية. «صافي حركة الفترة» = مبيعات الفترة − مشتريات الفترة، ولا يعيد احتساب رأس المال الأساسي.

«طباعة / حفظ PDF» يفتح مستند الكشف وحده باستخدام طباعة المتصفح. اختيار Save as PDF متروك لقدرات المتصفح؛ أوقف رؤوس وتذييلات المتصفح إن أردت عدم ظهور عنوان الصفحة. لا يوجد مولّد PDF خارجي.

أيقونات الويب مشتقة من الصورة المعتمدة دون تشويه أو قص الشعار. روابط manifest نسبية للعمل تحت `/-masarifi/`. التحقق النهائي من Add to Home Screen مطلوب على Safari/iPhone؛ لا تُضاف خدمة offline أو service worker.

التحقق: `npm test` و`npm run check`.
